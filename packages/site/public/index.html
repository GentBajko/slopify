Features

Make

  • Articles written by your AI model, with optional web research
  • Narration in your own voices: ElevenLabs, OpenAI, Cartesia or Inworld
  • Images and a thumbnail from your own prompts
  • Videos with moving images, captions and your pacing
  • PDF documents of the article, with contents, sources and a cover
  • YouTube descriptions with chapter timestamps, hashtags and tags

Control

  • Pause, resume and retry any step without starting over
  • Edit a finished project and rebuild only what changed
  • Checkpoints to approve work before narration, images or video
  • History keeps every version you saved

Reuse

  • Prompts written once, with {{keywords}} for the subject
  • Templates of a whole setup, applied in one click
  • Schedules that work through a list of topics, one per run
  • Intros and outros written once, reused on any video

Yours

  • Your own keys, or the Claude Code, Codex and Gemini CLIs you already use
  • Runs on your machine; files and keys stay there
  • Free and open source

How to use

  1. Node

    Slopify needs Node 26 or newer. Pick your line, or get it from nodejs.org.

    Windows
    winget install OpenJS.NodeJS
    macOS
    brew install node
    Linux
    nvm install 26
  2. Run it Copy a command from the top of the page. Slopify opens at http://127.0.0.1:6969.
  3. Docker

    On Linux, this keeps it running in the background, with project files in ~/Slopify/Projects:

    Docker
    npx @gentbajko/slopify@latest --docker
    Docker details

    The launcher asks once before setting up a small host helper (it needs systemd) so your Claude Code, Codex and Gemini CLIs run on your machine; their logins stay on the host. The database and credentials stay private in the slopify-data volume. Pick another folder with --projects-dir or SLOPIFY_DOCKER_PROJECTS_DIR. Open folder opens it through the helper, or shows its path on the machine running Slopify.

    Plain Docker is API-only and does not set up a host project folder. Keep the localhost binding: Slopify has no login.

    docker run -d --name slopify --restart always -p 127.0.0.1:6969:6969 -v slopify-data:/data ghcr.io/gentbajko/slopify:latest

    More in the Docker guide.

  4. Keys Add your provider keys and voices in Settings. They stay on your machine. Or use the Claude Code, Codex or Gemini CLI you are already signed in to.
  5. Prompts Write article, image and thumbnail prompts once, with {{keywords}} where the subject goes.
  6. Play Pick your prompts, fill in the keywords, review your setup, press Start.

All options

Every option is a flag or an environment variable of the same name. A flag beats the variable, the variable beats the default.

flag variable default does
--port SLOPIFY_PORT 6969 The port the app listens on.
--host SLOPIFY_HOST 127.0.0.1 The address it binds to. There is no login, so any other value prints a warning: whoever reaches the port controls the app and its keys.
--data-dir SLOPIFY_DATA_DIR ~/.slopify Where the database, the projects, the staged uploads and the logs live.
--no-open SLOPIFY_NO_OPEN the browser opens Keeps the browser shut and prints the URL instead.
no flag SLOPIFY_FFMPEG the bundled binary Path to an ffmpeg to render with. Slopify never picks one off your PATH.
