# Slopify 3.25.7

Released 17 October 2026.

- **An older project's shorts can be remade again.** On a project made before an earlier change to how Slopify recognises finished work, Choose what to remake said a short "has an unavailable prerequisite" and a run left the shorts out. Slopify now recognises the shorts it already picked, so they render again without picking new moments.
