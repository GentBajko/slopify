# Slopify 3.7.1

Released 4 October 2026.

## Release times on the project

- **Set release dates in the project itself.** The Video section has a Release block: the long video's and each short's release time, editable, with the time each must be uploaded and scheduled by. The long video can take one of the posting plan's free times, or be set to Not scheduled. They are the same times Calendar → Releases, Prepare upload and the Studio extension use.
