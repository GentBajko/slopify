# Slopify 3.7.1

Released 4 October 2026.

## Release times on the project

- **Set release dates in the project itself.** The Video section has a Release block: the long video's and each short's release time, editable, with the time each must be uploaded and scheduled by. The long video can take one of the posting plan's free times, or be set to Not scheduled. They are the same times Calendar → Releases, Prepare upload and the Studio extension use.
- **Swap with…** in the Release block: two videos trade their release times, and each one's shorts move with it.

## Project page

- **A run clock you can see.** While a project runs, its header shows "Working · 1:03:27", counting every second and checked against the server every 20 seconds. A stopped run shows its working time so far.

## YouTube Studio extension (1.1.3)

- **One click uploads one video.** Studio rebuilds its file picker while an upload starts; the extension took each rebuild for a new upload dialog and added the same short again (and Upload all seemed to start every short at once). Now each dialog takes one video, and the same upload is never added twice within a minute and a half. Download the extension again from Settings → YouTube Studio and reload it.
