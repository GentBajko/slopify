# Slopify 3.5.0

Released 2 October 2026.

## Square projects

- **A third frame format: 1:1.** Pick **Square** beside Landscape (16:9) and Portrait (9:16) in Play or Edit project. Images are drawn square, and a project that makes a video renders it 1080×1080, captions placed for it.
- **Shorts stay 9:16, and the thumbnail stays 16:9** for YouTube, whatever the project's format.
- Every image model Slopify offers draws square pictures, and the image-to-video clip models take them too.

## YouTube Studio extension (1.1.2)

- **Read Studio numbers no longer lands on "Oops, something went wrong".** Studio rewrote the address the extension opens; the extension now keeps its task aside before Studio's page loads, so each video's Analytics opens as it should. The same goes for the pages it opens for A/B tests, the finishing touches and the checks.
- **Download the extension again** (Settings → YouTube Studio) and reload it in `chrome://extensions`. It is version 1.1.2.
