# Slopify 3.10.1

Released 4 October 2026.

## YouTube Studio extension (1.2.2)

- **The schedule date sticks.** Studio stopped taking the date the extension typed on the Visibility step ("Studio didn't keep the date Slopify typed"). The extension now commits the date the way pressing Enter does, so the date and time are both set and you only press Schedule.
- **Shorts playlists.** Settings → Publishing → YouTube Studio warns when a playlist named for shorts is set to Videos and shorts: with that setting every short also went into your long-video playlists. Set it to Shorts only, and the long-video ones to Long videos only.

## Opening a long project

- **No more freeze when opening a finished long project.** Working out which narration chunk each transcript line came from (for the pencil beside each line) re-read every chunk for every line: a two-hour project froze the page for about 7 seconds. It now takes a few milliseconds.

## Upload status

- **One Studio video belongs to one upload.** When two projects have a short with the same title, the video Studio lists under that title was ticked as uploaded on both. Now a video already linked to a project's upload is never given to another.

Download the extension again from Settings → YouTube Studio and reload it.
