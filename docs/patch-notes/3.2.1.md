# Slopify 3.2.1

Released 30 September 2026.

3.2.1 lets one narration chunk be re-tagged without re-recording the whole narration.

## Narration

- A chunk whose text is edited in Edit project → Narration can carry its own delivery note. The note is added to the narration prep prompt for that chunk only, so its delivery cues can change (a calmer opening, say) while every other chunk keeps its recording.

## Upgrading from 3.2.0

- **Nothing becomes outdated.**
