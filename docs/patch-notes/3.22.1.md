# Slopify 3.22.1

Released 13 October 2026.

- **Subtitles work with a pronunciation alias.** A narration alias spoken as IPA (for example "Gygax's" said /ˈɡaɪɡæksɪz/) stopped the subtitles with "Local subtitles currently support English speech and Latin-script names only." Subtitles now time that word from its written form, the same way they do for a Pronunciation Glossary entry.

## Upgrading from 3.22.0

- A run stopped by that message goes on with Try again; nothing is voiced again.
