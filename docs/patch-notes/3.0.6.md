# Slopify 3.0.6

Released 28 September 2026.

3.0.6 writes more of what YouTube asks for: a comment to pin and two more titles to test, alongside the description and tags. A channel can send its videos to several playlists, and schedules follow the latest version of their template.

## Highlights

- **A pinned comment** written with every description.
- **Two more titles** for YouTube's title A/B test.
- **Several playlists** per channel, ticked per project.
- **Schedules use the template as it is now.**

## YouTube description

- The description step also writes a comment to pin under the video: a thank-you, a question viewers can answer from their own experience, a pointer to the chapters and an ask for the next topic. It shows under Tags in the project's YouTube section with **Copy**, and **Edit** keeps your changes through a rewrite. Your Description prompt can say how you want it.
- The same step writes two **Other titles** for YouTube's A/B Testing, next to the title in Studio. Each takes a different angle on the same video, within YouTube's 100 characters. They show in the YouTube section and in Prepare upload's Title step, with **Copy others**.
- **Write again**, next to Description, writes the description, tags, pinned comment and titles anew after asking. It no longer takes a trip through Edit settings and a remake.

## Publishing

- Settings → YouTube Studio → **Playlists** is a list for each channel (or the default list for all channels). Each playlist is either **On by default** or not.
- Prepare upload's Playlist step has a tick for each playlist, saved for that project, and the Studio extension ticks every chosen playlist in Studio.
- **Select all** above Prepare upload's steps ticks them all, or clears them.

## Schedules

- A schedule runs, previews and checks its topics against its template as it is now. It used to keep the template version it was made with, so edits to the template never reached its runs, and the Calendar showed the template's old name.

## Upgrading from 3.0.5

- **Nothing becomes outdated.** A description written before shows no pinned comment or other titles until you press **Write again**.
- A playlist you set before becomes the first entry of the channel's list, on by default.
- Update the Studio extension to have it tick more than one playlist. An older extension still ticks the first.
