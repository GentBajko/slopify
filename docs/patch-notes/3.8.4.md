# Slopify 3.8.4

Released 4 October 2026.

## YouTube Studio extension (1.1.4)

- **One video that won't open no longer stops the daily analytics read.** The extension reads each video's Analytics one tab after another, opening the next when the last reports back. A video Studio couldn't open (one deleted in Studio, say) never reported, so every video after it went unread that day. Now a tab that hasn't reported within four minutes is closed and the next video opens. Download the extension again from Settings → YouTube Studio and reload it.
