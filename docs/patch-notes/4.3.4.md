# Slopify 4.3.4

Released 10 November 2026.

The plan a run is made from is worked out once and shared, instead of again for every step that asks.

## A run no longer blocks the app

- **Ten places ask the project what it is making, and each worked it out from scratch** — the whole revision read back off disk, a check for every output and every picture, the article read again, every step derived from the narration up. With twelve pictures that was a few dozen times across a run and nobody saw it. With 240 it ran into the tens of thousands, one core went to nothing but that, and the app stopped answering.
- **It is now worked out once and handed to every caller that asks** while nothing it was made from has changed.
- **It is thrown away the moment anything does change** — any write to your data, a picture or an output whose file is no longer on disk, or a different model catalogue. The check is deliberately blunt, so it can only ever work the plan out more often than needed, never hand back one that has gone stale.
