# Slopify 3.0.8

Released 29 September 2026.

3.0.8 fixes a garbled narration sentence by itself instead of stopping the run.

## Highlights

- **Garbled narration is recorded again by itself.** A run no longer stops for a sentence the voice mumbled or skipped.

## Narration

- When captions find the narration no longer matches the text (the voice garbled or skipped a sentence), Slopify records that narration chunk again by itself, rebuilds the narration, captions and video, and carries on. It used to stop the run until you pressed Regenerate on the chunk in Edit project → Narration and continued.
- Each chunk gets two tries. The step says which try is running; if the audio still doesn't match after both, the voice reads something its own way (a year, an abbreviation or a name), and the step says to reword that sentence in Edit project → Narration.
- Uploaded narration, captions you edited by hand and multi-voice turns aren't retried: they stop and ask, as before.

## Everywhere

- **Start Slopify when I log in** belongs to one data folder. A second Slopify on the same account (another `--data-dir`) sees the switch off and can no longer remove or take over the first one's login entry.

## Upgrading from 3.0.7

- **Nothing becomes outdated.** Retries start with the next run that finds a mismatch.
