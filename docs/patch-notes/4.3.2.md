# Slopify 4.3.2

Released 9 November 2026.

Two fixes: the settings screen opens again, and a video with many images gets scenes worth drawing.

## Edit settings opens again

- **It crashed on every project in 4.3.1**, with `createHash is not a function` and nothing to do but Try again. The form read the count of names you carry from Settings → Voices → Name pronunciations, and the code it read it from also stamps the list's version by hashing — which a browser cannot do. It now reads the count from the parser alone.
- **A check keeps it from coming back.** The web build's imports are walked from the router, and anything that reaches a Node built-in for its values fails the suite rather than the screen.

## Scenes are written a batch at a time

- **Every image's scene came from one request.** Asked for twelve the model spent about 42 words on each; asked for 240 it rationed them down to 18, and the first thing it dropped was the material, light and colour an image is drawn from. "Broken towers of dark stone, collapsed palaces and scorched fields under a smoke-heavy sky" became "a demon lunges at an adventurer", and the pictures came out pale and simple while the prompts, the model and the settings were untouched.
- **Scenes are now written sixteen at a time,** each call reading only the stretch of the article its own pictures are shown over, and each image waiting on the batch that writes its scene. No answer is long enough to be worth compressing.
- **A short video is unchanged** — one batch, the same single step it always had.
