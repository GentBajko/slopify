# Slopify 3.9.1

Released 4 October 2026.

## YouTube Studio extension (1.2.1): a new popup

- **Slopify's look.** The toolbar popup uses Slopify's colours and typeface, with the pairing shown as a chip in its header and a settings button beside it.
- **Every project at a glance.** Projects are listed soonest first, each with a dot per upload (filled once it is on YouTube, orange when late) and when its next one goes public.
- **One button per upload.** A project shows Upload all its shorts as its one main button, then the video and each short with what it is, its title, its state (Ready · goes public …, On YouTube, Late, Not rendered yet) and its own Upload or A/B test button.
- **The footer** reads Studio now and opens Slopify.

Download the extension again from Settings → YouTube Studio and reload it.
