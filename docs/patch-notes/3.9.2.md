# Slopify 3.9.2

Released 6 October 2026.

- **Writing the YouTube description again no longer remakes the video.** A video with chapter cards draws them from the description, so writing the description again (YouTube → Write again) used to render the whole video again. A finished video now keeps the description it was drawn from: only the description, tags, pinned comment and titles are written again. The video is still remade when something it shows changes (its images, narration, captions or edit settings), and then its chapter cards follow the current description.
