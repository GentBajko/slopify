# Slopify 3.4.0

Released 2 October 2026.

## Calendar → Releases

- **Every video and every short has its own release time**, shown week by week in Calendar → **Releases**: the long video on one line, its shorts beside it, each with the time it must be uploaded and scheduled by.
- **Upload in time for the checks.** Each item is due a set number of hours before its release (24 by default; change it in Settings → YouTube Studio), so YouTube's copyright and ad checks finish while it is still private. An item past that time and not on YouTube shows **Late**.
- **See where each one stands:** not rendered, upload by…, filled in Studio but not scheduled, or scheduled, with **checks clear** once Studio's Content list shows no restrictions.
- **Move anything.** Click a time to change it; a long video can also be set to not scheduled. A free time of your plan offers the finished projects that fit it: pick one and press **Put it here**.

## Posting plan

- **Starts empty.** Nothing is scheduled until you add a long video in Settings → YouTube Studio → Posting plan.
- **No more A, B, C.** One line per long video, each with its own day and time and as many shorts as you post for it (**+ Short**, and × to remove one).
- **Series.** Each line can take any project or only one series, read from the project's titles (the part after "|"), so a week of three of one series and one of another fills itself the right way.
- **Shorts never share an hour** with another release; one that would takes the next time of its line.

## YouTube Studio extension (1.1.0)

- **Upload all shorts, one at a time.** The next short opens only after the previous file has fully uploaded, so leaving the page can't stop an upload.
- **The popup lists what's due first**, with each upload's "by" time, or **late**.
- **Reads the checks.** While a scheduled video's checks aren't clear, the extension reads Studio's Content list in the background every two hours.

## Upgrading from 3.3.1

- **Your plan and your projects' times carry over.** A project that already had a slot keeps it; its shorts get their times the first time you open Calendar → Releases.
- **Update the extension** (Settings → YouTube Studio → Download, then reload it in `chrome://extensions`), or let the Chrome Web Store update it once version 1.1.0 is approved.
