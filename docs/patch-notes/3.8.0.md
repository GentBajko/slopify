# Slopify 3.8.0

Released 4 October 2026.

## Release times live in the schedule

- **Each schedule sets its own release times.** Edit a schedule (Calendar → Schedules → Edit) and press **Set release times**: for each day it runs there is a line with the long video's weekday and time and one for every short its template makes. The number of shorts comes from the template, so there is nothing to add or remove by hand. Times are in the schedule's time zone.
- **A project goes out on its run's line.** A project a schedule made takes the next free time of the line for the day it ran (else another of that schedule's lines), and its shorts follow it, never in the same hour as another release. Calendar → Releases shows each line under its schedule's name.
- **Settings → YouTube Studio no longer has a posting plan editor.** It points to the schedules and keeps the upload lead time and the pinned comment. A posting plan saved there before still applies (to projects no schedule made, and when a schedule's own times are taken) until you press **Remove the old plan**. Release times already given don't change.
