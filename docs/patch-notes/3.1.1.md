# Slopify 3.1.1

Released 30 September 2026.

3.1.1 lets the shorts draw figures the way the video does.

## Shorts

- The shorts' image prompt (**Shorts → Image prompt**) takes `{{Appearance}}`, like the video's image and thumbnail prompts. Each short gets the subject's researched look and those of the figures its clip names, so a figure looks the same in the shorts as in the video.
- A `{{Scene}}` line in the shorts' image prompt is left out: each short's images already show what is said at that moment.

## Help

- The **Prompts** page of the wiki explains the two keywords Slopify fills itself, `{{Scene}}` and `{{Appearance}}`: what each becomes, where it works, and an example.

## Upgrading from 3.1.0

- **Nothing becomes outdated.** Only a shorts image prompt that names `{{Appearance}}` changes, the next time its shorts are made.
