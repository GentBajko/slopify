# Slopify 3.10.3

Released 6 October 2026.

- **A link your description prompt asks for is kept.** Slopify told the AI model never to put a link in the description's summary or the pinned comment, so a prompt asking for one (each video's own page on your website, say) got a description that mentions the page without its address. The model still never makes a link up, but one your prompt gives or describes is written exactly as asked. Links from Settings → Channel links keep working as before.
