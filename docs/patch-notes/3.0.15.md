# Slopify 3.0.15

Released 30 September 2026.

3.0.15 makes a garbled narration chunk get recorded again even when the project is busy.

## Fixes

- When the captions caught a garbled sentence, Slopify said it was recording that narration chunk again, but if another step of the project was still running at that moment (its PDF, say), the retry gave up and the video stayed failed. The retry now waits for that step and starts as soon as it finishes.

## Under the hood

- Faster CI and releases: Docker images build beside the npm publish, the Windows install check uses one warm cache, and unchanged Windows and Docker checks are skipped.

## Upgrading from 3.0.14

- **Nothing becomes outdated.**
