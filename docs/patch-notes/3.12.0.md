# Slopify 3.12.0

Released 7 October 2026.

- **Keep or redo your shorts.** Changing a project's shorts no longer throws them all away. When a change would pick the moments again (another count, length or Shorts prompt, or a new intro or narration edit that moves the timing), Slopify keeps the finished shorts: same moment, title, image prompts and images, only rendered again. In Edit project → Shorts, Keep finished shorts lists them with a tick each, so you choose which stay; Pick different moments still picks every short anew.
  - **Raising the count** keeps every short and picks only the extra ones, at moments the kept ones don't use.
  - **Lowering the count** keeps the ones you tick, numbered 1, 2, 3 in their order, so release times, uploads and the extension's "Short N" line up. A short already on YouTube moves its record with it.
  - **A kept short is remembered by its sentences**, so a new intro just moves it. When its narration was rewritten, the pick stops and names it, so you can pick a new moment for it or drop it.
- **The remake dialog names shorts work** ("Short 2: render", "Shorts: pick the moments") instead of "Output".
