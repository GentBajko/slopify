# Slopify 3.11.3

Released 6 October 2026.

- **A project no longer waits on steps it doesn't need.** Steps an edit planned (a narration or a render) were carried into every later version while their inputs looked the same, even once a later save showed the result already made was the one wanted. The project then stayed waiting, its video step pending, and wasn't offered as ready to upload. A step that never started is now carried only while it is for what the version wants; otherwise the finished result is used.
