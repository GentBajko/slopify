# Slopify 3.11.4

Released 6 October 2026.

## YouTube Studio extension (1.3.1): deleted videos are noticed for real

- **The deleted-video check now reads Studio signed in.** In 1.3.0 the extension read each video's page from its own side of the tab, where Studio answered as if signed out, so a video deleted in Studio was never noticed and stayed "On YouTube". It now reads the page as Studio itself does.
- **Read Studio now checks at once.** The popup's Read Studio now also checks which videos were deleted, instead of waiting for the two-hourly check.
- **It says what it found.** Each check writes one line to the Studio tab's console: how many videos it checked, how many are there, deleted, missing or unread, and which it forgets.

Download the extension again from Settings → YouTube Studio and reload it.
