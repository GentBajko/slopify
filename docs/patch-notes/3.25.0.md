# Slopify 3.25.0

Released 16 October 2026.

- **The Antigravity CLI replaces the Gemini CLI.** Google retired the Gemini CLI for personal accounts and moved them to Antigravity. Settings → Providers now shows **Antigravity CLI** where Gemini CLI was, and projects that chose it keep that choice. Install it with `curl -fsSL https://antigravity.google/cli/install.sh | bash`, then run `agy` once in a terminal to sign in with your Google account. Research searches the web with it, and picture reviews work.
- **Turning on Soften breaths or Soften S sounds no longer rewrites the description or re-picks the shorts.** Softening never moves a word, but turning it on used to time every word again and then write the YouTube description and the shorts' pick again. Now a finished project keeps its timing, description and shorts' pick. Only the narration is joined again and the video and shorts are rendered again.

## Upgrading from 3.24.0

- A model saved for the old Gemini CLI, such as `gemini-2.5-pro`, isn't on Antigravity's list. Pick a new one in Edit project → Providers. The error message says so if you forget.
- For a finished project, turning softening on now remakes only the narration, the video, the shorts' renders and the PDF.
