# Slopify 3.0.13

Released 30 September 2026.

3.0.13 makes every page update live again, adds run sounds, and fixes Restore and a thumbnail change that remade every image.

## Highlights

- **Pages update live again.** Steps, images, progress and finished runs show up without refreshing, on every page and in every tab.
- **Run sounds.** A chime when a run starts and a different one when it ends.
- **History → Restore works again** on projects with scenes, looks, shorts or a YouTube description.

## Live updates

- Each page now keeps one live connection instead of one per project it shows. With a few tabs open, the connections ran out and the page's own requests waited forever: updates arrived but nothing could reload.
- A run that goes on after an edit (a video still rendering after a thumbnail redo) shows its progress again.
- The projects list, home and calendar move when steps start and finish, not only when a project changes.
- The video render's progress moves in tenths of a percent, so a two-hour render moves every few seconds.
- Pages showing a running project also look again every 15 seconds, in case an update was missed.

## Run clock and cost

- The run clock keeps counting through work carried over from before an edit, instead of freezing.
- **Cost so far** shows the run's working time once it stops, for example "2 h 14 min of work".

## Notifications

- **Run sounds** (Settings → Notifications, on by default): two rising notes when a run starts, three brighter ones when it finishes, fails or waits for you. **Play start** and **Play end** let you hear them. With browser notifications on, a start also shows "Started: *title*".

## Fixes

- **History → Restore this revision** stopped with "unknown kind of step" on projects with Scenes from the article, `{{Appearance}}`, shorts, a YouTube description, levelled narration or animated images.
- Changing a project's thumbnail settings marked every image outdated. The thumbnails' scenes are now written by a step of their own in the Thumbnail stage.

## Upgrading from 3.0.12

- **Nothing becomes outdated.** A project whose thumbnail prompt uses `{{Scene}}` writes its thumbnail scenes in the new step the next time the thumbnail is made.
