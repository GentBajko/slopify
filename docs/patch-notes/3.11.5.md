# Slopify 3.11.5

Released 6 October 2026.

## YouTube Studio extension (1.3.2): uploads Studio scheduled count as uploaded

- **An upload whose confirmation was missed is caught up.** The extension marks an upload as on YouTube when Studio's "Video scheduled" or "Video published" message shows. When that was missed (the dialog closed early, or the next short opened), the upload stayed at "Upload again", and its captions, end screen and pinned comment never followed. The Studio check (Check for deleted videos, Read Studio now, or every two hours) now also reads these uploads: one Studio has scheduled or published counts as uploaded and its Details touches follow; a draft stays as it is.

Download the extension again from Settings → YouTube Studio and reload it.
