# Slopify 3.14.0

Released 9 October 2026.

- **Project folders you can find your way around.** Each project's folder is now named after its title instead of a code, and its files are sorted the way you look for them:
  - `Upload/`: the current version, ready to publish: the video, thumbnails, subtitles, description, tags, titles, pinned comment, PDF, article, and `Shorts/1 - <title>.mp4`.
  - `Working/`: what that version was made from: images, each narration chunk, research, subtitle timing, render settings.
  - `History/<date>/`: older versions (an earlier render, the narration before a voice change). Delete a day's folder, or all of History, to get the space back; going back to that version makes its files again.

  Slopify sorts your existing projects in the background after the update, a few at a time, without stopping the app; a project is sorted once nothing of it is running. Nothing is copied, so it takes no extra disk space, and your backups work in every version as before. Files you add to these folders yourself are never removed, and a folder in Projects that Slopify didn't make is left alone. See [Where Your Files Live](https://github.com/gentbajko/slopify/wiki/Where-Your-Files-Live#inside-a-project-folder).

  **Don't go back to a version older than 3.14 after this update:** older versions only know folders named by project code and would remove the readable ones when they start.
