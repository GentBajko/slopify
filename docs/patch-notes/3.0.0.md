# Slopify 3.0.0

Released 27 September 2026.

3.0 is about the steps around the video: Slopify finds its own topics, reviews its own work, knows what a run cost, waits out plan limits instead of failing, and fills in YouTube Studio for you. You still press Publish. The whole app has a new design, and every control now explains itself.

The full list, from 2.0.1 to 3.0.0, is in **Slopify 2.0 to 3.0**, the next entry in Settings → Patch notes.
