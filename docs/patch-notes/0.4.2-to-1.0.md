# Slopify 0.4.2 to 1.0

Versions 0.4.3 to 1.0.0, released 9 to 13 September 2026 (0.4.2 shipped on 3 September).

This is the stretch where Slopify went from a pipeline that ran once, start to finish, to something you can live with: pause it, change your mind halfway, edit a finished project without paying for everything twice, and leave it running on a schedule. It also picked up free local captions, the Gemini CLI, Inworld voices and an updater. 1.0.0 is the first release where a finished project is never a dead end.

## Highlights

- Captions, made on your machine for free: English word timing with a 95 MB speech model, no caption service and no key.
- Edit any finished project. Slopify keeps every version and remakes only what your change affects.
- Pause and resume a run, and switch its providers while it is paused.
- A cost review before anything starts, with the exact inputs, prices and a readiness check.
- Review checkpoints hold Audio, Images or Video until you approve them, while the rest keeps going.
- Templates for setups you reuse, and daily, weekly or one-off schedules that run them.
- Gemini CLI joins Claude Code and Codex as a text provider, using the login you already have.
- Inworld TTS-2 and TTS-2 Flash voices.
- Update from inside the app with one click.

## What's new

### Getting started
- An interactive tutorial walks from API keys to a downloaded video in 18 steps (19 from 0.5.1), highlighting the real controls on each screen. Open it from Tutorial in the navigation or Start tutorial on an empty Projects page.
- The tutorial remembers where you were across reloads and never starts a run for you.
- Two ways to install on slopify.stream: `npx @gentbajko/slopify@latest` with nothing to install, or `npm install -g @gentbajko/slopify` and then `slopify`.

### Runs
- Pause and Resume. Pausing stops active work, keeps every finished piece and survives an app restart.
- Article is the only required stage. Research, Audio, Images, Thumbnail and Video can each be Off.
- With Images off and Audio on, the run exports a 48 kHz stereo WAV. With Audio off, it renders a silent MP4 at 5 seconds per image.
- Images from a saved prompt and prewritten thumbnails start straight away, beside research and writing.
- Uploaded narration is used as it is.
- Play is four sections, with a preview of the output shape and caption style next to the controls.
- Play drafts save to this computer as you type, uploads included, and come back after a restart.
- Review shows the exact inputs, prices and catalogue date before you start. Nothing runs until Start.
- Review also checks that every provider, model and voice the run needs is ready.
- Batches: several title or keyword variants from one setup, run one after another.
- Provider-aware queues cap how many requests go to each provider at once.

### Editing finished projects
- Change the settings, article, narration, images or captions of any project, finished or not.
- Every save is a new version in History. Restore any earlier one.
- Before a rebuild, Slopify lists the outputs your change affects and what they cost. Work that is unaffected is reused, not paid for again.
- Each project keeps its own copy of the prompts it was made with, so editing a Library prompt never changes an old project.
- Edit a single image, a caption line, or the article text by hand.

### Review checkpoints
- Hold Audio, Images or Video/export for approval. Independent work carries on while one part waits.
- Approve held work from the project's progress view. Approvals survive restarts and later edits.

### Templates and schedules
- Save a project's setup as a named template and apply it in Play. Templates keep versions, so an old draft is never changed under you.
- Schedules run a template once, daily or weekly, in your time zone, with up to 49 keyword variants and an optional spend limit.
- Each schedule has a run history and Pause, Resume, Cancel and Delete. Missed runs follow a policy you choose, and a run never overlaps the one before it.

### Captions and fonts
- Free English captions for new and existing narrated projects, timed word by word to the actual speech.
- SRT, VTT and ASS files, and captions burned into the video.
- Five caption positions, a font size and a live preview in the real output shape.
- Bundled Barlow, your installed fonts, or upload a TTF or OTF up to 32 MiB.
- Changing only the caption style reuses the narration and the WAV instead of making them again.
- When the narration skips a short passage, captions resync on the following words and add a note beside the caption download saying what was missed.

### Narration
- Inworld TTS-2 and TTS-2 Flash. TTS-2 takes up to 100,000 characters per job.
- Split narration by characters as well as by paragraph or word count: 3,000 characters by default, always on a sentence end.
- Hear narration while it is still being made, and watch the article write itself.

### Providers and models
- Gemini CLI as a text and research provider, signed in with the login you already have.
- Set the path to each CLI in Settings when Slopify can't find it on your PATH.
- Model lists load from the provider or the installed CLI, with a refresh button and space to type a model ID.
- A curated model catalogue with prices, context sizes and thinking settings, refreshed from GitHub.

### Project page
- A focused workspace: stage list on the left, the output of the chosen stage beside it, and a direct download of the final file.
- Overall progress next to each stage's own progress.
- Open folder next to every download.

### Updates and upkeep
- An update button checks every 15 minutes and installs on one click. It waits for active work, checks the new version starts, and rolls the database back if it doesn't.
- Settings exports and imports a backup of your templates, prompts, voices and settings. Provider keys are never included.
- Disk usage per project, cleanup of files no project uses, and a diagnostics download with no secrets in it.

## Fixes

- A missing ffmpeg is downloaded into the app's data folder and checked before any provider work starts.
- Claude Code no longer applies your personal coding setup to article writing.
- Google's image errors are read correctly; an image quota of zero fails once with a clear message instead of retrying.
- Slideshow zoom is faster and travels from 100% to 122.5%.
- The update indicator no longer sticks on Updating after a check finds nothing new.
- A stalled or interrupted update recovers its status on the next start.
- Many fixes to editing and rebuilds: regenerated articles open current, uploaded audio can be replaced by generated narration, and interrupted rebuilds recover their unfinished outputs.
- Many fixes to Play drafts: unfinished uploads, image counts, empty chunk sizes and discarded drafts are all kept or recovered correctly.
