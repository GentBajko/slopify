# Slopify 3.24.0

Released 15 October 2026.

- **Captions go in during the upload.** The Studio extension now uploads a long video's captions in Studio's upload dialog, on the Video elements step, instead of on the video's Details page after it is scheduled or published. Press Next to Video elements as usual: Add subtitles → Upload file → With timing → the project's captions file → Done happen by themselves, and a toast says "Captions uploaded." The extension still never presses Next, Save or Publish in the upload dialog.
- Studio keeps Add subtitles greyed out until the video has processed far enough to play and has a video language. Until then a toast says Studio's own reason once, and the captions go in as soon as Studio allows it. Set the video language in Details (Show more → Language) if your channel has no default language.
- If you move on before that, or Studio's dialog isn't what the extension expects, a toast says so and the captions are uploaded on the Details page after the upload, as before.
- A video whose captions went in during the upload gets no Details-page visit for captions; one still opens when it needs an end screen or a related video, and skips the captions.

## Upgrading from 3.23.0

- The extension goes to 1.5.0. Loaded unpacked from Slopify's folder, it reloads itself once it has been idle for 45 minutes; a store install updates through the store.
