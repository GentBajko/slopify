# Slopify 3.8.6

Released 4 October 2026.

## YouTube Studio extension (1.1.6)

- **The schedule's date and time stick.** The extension typed the time while Studio was still taking the date, so the date was lost. Now it presses Enter on the date, waits until Studio shows it, and only then types the time and checks both. Dates and times are typed the way your Studio shows them ("6 Oct 2026" or "Oct 6, 2026", "17:00" or "5:00 PM").
- **Shorts are recorded once uploaded.** Studio shows a short's link as youtube.com/shorts/…, which the extension didn't recognise, so a short's upload was never recorded: Upload all didn't move on to the next short, and the related video wasn't set. Both kinds of link are read now.
- **The popup shows when each upload goes public**, not the time it should be uploaded by; one too close to going public still says late.
- A short's file size shows in MB, not "0.0 GB".

Download the extension again from Settings → YouTube Studio and reload it.
