# Slopify 3.0.14

Released 30 September 2026.

3.0.14 fixes two things in the Library: **Used by** on Review and Script prompts, and renaming a prompt or an intro/outro that templates and drafts still use.

## Highlights

- **Renaming a prompt no longer breaks what uses it.** Templates, schedules and open Play drafts take the new name.
- **Used by is right for Review and Script prompts.**

## Library

- Renaming a prompt or an intro/outro now renames it in every template and every Play draft you are still editing, so they keep using it. Schedules follow their template. Before, they kept the old name and fell back to the copy saved with the template.
- A project keeps the name its run used. **Used by** still lists it after a rename.

## Fixes

- **Used by** on a Review or Script prompt listed the templates and projects that used *image* prompts of the same name. It now lists the automatic reviews that pick the Review prompt, and the multi-voice script runs that pick the Script prompt.
- **Used by** now lists a schedule by the template as it is now, which is what the schedule runs, instead of the version it was saved with.

## Upgrading from 3.0.13

- **Nothing becomes outdated.** Templates and drafts that already name an old name keep working as before; the next rename carries them along.
