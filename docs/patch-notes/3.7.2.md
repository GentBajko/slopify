# Slopify 3.7.2

Released 4 October 2026.

## YouTube Studio extension

- **Upload one uploads one.** The extension's Upload now leaves only that video waiting, and Upload all Shorts only that project's shorts. Before, anything left waiting from an earlier click stayed in line, and the next upload dialogs took it. Together with extension 1.1.3 (one video per upload dialog), shorts go up strictly one at a time. If you're still on 1.1.2, download the extension again from Settings → YouTube Studio and reload it.

## Layout

- **The sidebar always reaches the bottom of the window.** In a short or zoomed window scrolled to the end, the sidebar could stop partway down and leave an empty band.
