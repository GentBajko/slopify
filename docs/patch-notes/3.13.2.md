# Slopify 3.13.2

Released 8 October 2026.

- **Uploaded videos no longer show as Paused.** A project you uploaded that was paused, or had a leftover step from an edit after the upload, showed as Paused or Waiting in the project list and on its page. An uploaded project with nothing queued to run now shows as Done. A remake you start on an uploaded video still shows as running until it finishes.
