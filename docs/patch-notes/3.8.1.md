# Slopify 3.8.1

Released 4 October 2026.

- **A schedule's release times also take its series' other projects.** A project queued by hand from the schedule's topics (or any project whose title ends with the same series as the schedule's template, the part after "|") takes the schedule's release times too, not only the projects the schedule ran itself.
- **Deleted on YouTube.** Each upload in the project's On YouTube list has a Deleted on YouTube button: press it after deleting the video in Studio, and Slopify forgets it, so the extension offers the upload again.
- **Release calendar reads plainly.** Each time is marked "goes public", and the upload deadline reads "Ready · upload before …": you can upload any time before it. It turns orange only in its last day, and red once it has passed.
