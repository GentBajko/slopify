# Slopify 3.2.2

Released 1 October 2026.

3.2.2 names a refused short's picture for what it is and lets Soften and retry fix it.

## Shorts

- When the Codex CLI's image tool refuses a picture under its safety rules, the step now says so ("refused to make this image under its content rules", with Codex's own reason) instead of "the saved file could not be read".
- A short's refused picture can be fixed with **Soften and retry** in the Video section, as Images and Thumbnail pictures already could: the project's AI model rewords the prompt without what the filter flagged, then the picture is drawn again.

## Upgrading from 3.2.1

- **Nothing becomes outdated.**
- A short that already failed with "the saved file could not be read" needs one more **Try again**; if the picture is refused again, the Soften and retry button appears.
