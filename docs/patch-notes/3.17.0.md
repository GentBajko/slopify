# Slopify 3.17.0

Released 10 October 2026.

- **YouTube numbers are gone.** Studio's export only carried daily figures for the few videos its chart showed, so the numbers were incomplete. The **YouTube numbers** tab in Channels is removed. So are the views and CTR on the Projects list and the numbers line under each video in **On YouTube**. The extension no longer exports the Analytics view every day or visits each video's Analytics, and the popup's **Read Studio now** is gone. **Library → A/B results** stays: once a day the extension still reads a running A/B test's result from the long video's Details page. (Extension 1.4.0.)

## Upgrading from 3.16.0

- **Nothing becomes outdated.**
- The extension loaded from Slopify's own folder switches to 1.4.0 by itself. The store version updates through the store.
