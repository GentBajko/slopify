# Slopify 3.0.11

Released 29 September 2026.

3.0.11 keeps the calendar tidy on busy days and brings dependencies up to date.

## Highlights

- **A busy day no longer stretches the calendar.** Every day keeps the same height, however many projects it holds.

## Calendar

- The week grid uses the full width of the page.
- A day shows its first three projects, then "+N more"; press it to see the rest, and "Show fewer" to fold them again.

## Under the hood

- Updated React Router, Vite, YAML, Biome and Wrangler, and the Docker image's build actions.

## Upgrading from 3.0.10

- **Nothing becomes outdated.**
