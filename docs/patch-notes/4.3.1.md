# Slopify 4.3.1

Released 9 November 2026.

Updating Slopify is now a thing you can see, not a thing you go looking for.

## The update has its own button

- **It sits in the rail, under Assistant and above Help, and it is always there** — not a row at the foot of the Help menu, which is where it used to hide. Whether there is a new version is a question people ask of the app, not of its help.
- **Under the word is the version you are running.** No menu to open, no About page to find.
- **A version ready to install stands under that in green,** `→ 4.3.2`, with the whole button in the accent's ink, as a waiting update always looked. One press installs it; the button says so before you press, on it and to a screen reader: installing restarts Slopify, and anything running finishes first.
- **The arrow turns while it looks.** A check used to give nothing back until it had an answer, so a press felt like nothing happened. Now the button turns, says "Checking for updates…", and takes no second press until it is done. It stays still where the system asks for less motion.
- **On a phone** the same button sits in the top bar between Search and Help, with the versions left off, where there is no room for them; Settings → About still carries them in full.
