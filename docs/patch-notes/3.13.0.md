# Slopify 3.13.0

Released 8 October 2026.

- **Editing the article re-voices only what you changed.** Slopify splits the narration into chunks by length, filling each one sentence by sentence from the top. Removing or adding a sentence near the start moved every chunk boundary after it, so every chunk looked new and the whole narration was voiced again. A save that changes the article or narration text now keeps the chunks it had wherever their text is unchanged, and only cuts the edited stretch again. Dropping one line from the top of a 29-chunk narration now re-voices 1 chunk instead of 29. Changing the chunk size in settings still splits the whole narration again.
