# Slopify 3.8.5

Released 4 October 2026.

- **Playlists for long videos, shorts or both.** Each playlist in Settings → YouTube Studio → Playlists says what it takes: Videos and shorts, Long videos only, or Shorts only. A channel with a playlist of its own for shorts no longer gets its shorts added to the long videos' playlist.

## YouTube Studio extension (1.1.5)

- **Ad suitability is answered for you.** When an upload reaches Studio's Ad suitability questions, the extension ticks None of the above and presses Submit rating, then says so. If Studio's page doesn't show them as expected, it leaves them to you and says what to do. Download the extension again from Settings → YouTube Studio and reload it.
