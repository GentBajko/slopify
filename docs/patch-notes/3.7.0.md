# Slopify 3.7.0

Released 4 October 2026.

## Projects by channel

- **Move projects to another channel.** In Projects, search (for example `ground.`) or pick a filter, then **Move the N shown to** a channel. A project's page has **Move to channel…** in its More menu. Nothing a project made changes; it shows in that channel's list and uses its brand and playlists.
- **One list per channel.** With All channels picked in the sidebar, the Projects list groups projects under each channel's name. Pick one channel in the sidebar to see only its projects.
