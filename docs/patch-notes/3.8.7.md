# Slopify 3.8.7

Released 4 October 2026.

## YouTube Studio extension (1.1.7)

- **Monetization is turned on for long videos.** On a long video's Monetization step, the extension opens Select, chooses On and presses Done, which brings up Ad suitability. Shorts have nothing to choose there.
- **Ad suitability, read from Studio's real page.** The extension ticks None of the above, waits for Submit rating to enable, presses it, and waits for Studio to say the questionnaire is locked. A questionnaire submitted already is left alone. You still press Next yourself to reach it.

Download the extension again from Settings → YouTube Studio and reload it.
