# Slopify 3.6.1

Released 3 October 2026.

## Channels → YouTube numbers

- **A chart you can read.** The Studio export's daily figures are now one chart above the table, with dates along the bottom, values up the side and gridlines. Hover a day to see every compared video's value on it.
- **Choose what to compare.** Tick videos in the table's Chart column; the five with the most of the chart's metric are ticked to start. Show it per day, as a 7-day average or as a running total; by date or by days since each video's release, so a new video lines up against older ones; over all time, the last 90 days or the last 30.
