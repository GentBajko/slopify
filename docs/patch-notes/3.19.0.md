# Slopify 3.19.0

Released 11 October 2026.

- **Remove breaths.** A new switch beside the pauses between sentences (Play → Video and style, Edit project → Pauses and volume) mutes the loud in-breath some voices take after almost every comma and full stop, Inworld's TTS-2 among them. Words, pauses and captions stay exactly where they were. It is off by default. See `docs/breaths.md`.

## Upgrading from 3.18.2

- Nothing becomes outdated. Turning Remove breaths on for a project joins its narration again from the pieces it already has; no speech is made again.
