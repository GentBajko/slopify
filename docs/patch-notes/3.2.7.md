# Slopify 3.2.7

Released 1 October 2026.

3.2.7 lets the Slopify Studio extension put the video into YouTube Studio's upload dialog itself.

## YouTube Studio

- After **Fill in YouTube Studio**, the extension adds the video file to Studio's upload dialog as soon as it opens on Select files, then fills the details as before. Studio uploads it as a private draft, exactly as a file you drop in; nothing is published, and you still check everything and press Publish yourself.
- If the video can't be added (Slopify isn't running, or Studio's dialog changed), the extension says so: drop the file in yourself from Open folder in Prepare upload.

## Upgrading from 3.2.6

- **Download the extension again** (Settings → YouTube Studio → Download) and replace the old one; it is version 0.2.0. Pairing carries over when you update it in place.
- **Nothing becomes outdated.**
