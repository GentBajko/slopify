# Slopify 3.14.1

Released 9 October 2026.

- **Videos finish sooner.** After rendering a video, Slopify checks how loud it came out. That check decoded the whole picture just to read the sound, which took 20 minutes or more for a two-hour video and slowed down any other render running at the same time. It now reads only the sound, so a video is done a few minutes after its render reaches 100%.
