# Slopify 3.8.3

Released 4 October 2026.

- **A narration chunk Slopify records again by itself really does get recorded.** If its first try found the project busy, Slopify kept "busy" as that try's answer and gave it back every time after, even across restarts, so the video stayed failed and the update waited on it forever. A busy answer is no longer kept: the next look asks again and records the chunk. Retries stuck this way before the update start on their own once it is installed.
