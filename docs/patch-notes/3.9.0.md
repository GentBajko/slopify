# Slopify 3.9.0

Released 4 October 2026.

## Studio's numbers, every day, by themselves

- **The extension exports your Analytics view daily.** Paste the address of your YouTube Studio Analytics → Advanced mode view (with the columns you chose) into Channels → YouTube → From Studio's export, and press Save view. Once a day the extension opens it in the background with the end date moved to today (the start stays as you set it), presses Export → Comma-separated values, and brings Studio's zip straight into Slopify: no file lands in your Downloads, and no import by hand.
- **Every video's numbers come from that one export.** Each video you uploaded with Slopify gets its views, impressions, click-through rate, average view and watch hours from it, on its project page and in Channels → YouTube. The extension no longer opens each video's Analytics; it only opens a long video whose A/B test is running, to read its result.
- **The channel's total.** The export's third file (Totals.csv) is read too: tick Channel total above the chart to draw the whole view's daily figure.

## Channels → YouTube

- **One video's chart opens under its row.** Click a video in the From Studio's export table (or its arrow) to see its own chart; the grid of every video's chart is gone.
