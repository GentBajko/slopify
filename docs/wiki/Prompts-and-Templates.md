# Prompts and Templates

Your videos are made from reusable pieces you write once: prompts, intros and outros, and templates that hold a whole setup. They live on two pages in the rail, **Prompts** and **Templates**. The PDF looks, the Pronunciation list and What worked on YouTube that sat beside them before are now where you use them.

**Where to find it:** **Prompts** and **Templates** in the rail (`G` then `L` opens Prompts, `G` then `T` Templates). An old link to the Library opens Prompts.

## Where everything is

| What | Where | Page |
| --- | --- | --- |
| **Prompts**: the instructions for articles, images, thumbnails, narration preparation, YouTube descriptions, shorts, reviews, speaker scripts and posts, each with `{{keywords}}` where the subject goes | **Prompts**, one kind at a time down the left | [Prompts](Prompts) |
| **Intros** and **Outros**: short narrated openings and closings, said word for word or written by the AI for each video | **Prompts** → **Intros** / **Outros**, at the foot of the kinds | [Intros and outros](Intros-and-Outros) |
| **Video templates**: saved setups a video starts from, and the starter templates | **Templates** → **Video templates** | [Templates](Templates) |
| **Poster templates**: designed pieces such as posters | **Templates** → **Poster templates** | [Templates](Templates) |
| **PDF looks**: how the PDF made from the article looks | Create → **Extras** → **PDF of the article** → **Edit PDF looks ↗**, or Settings → **Production defaults** → **PDF look** → **Edit PDF looks** | [PDF looks](Document-Themes) |
| **Narration aliases**: words the narrator says differently from how they are written, such as Dr. as Doctor | Settings → **Voices** → **Pronunciation** | [Aliases and glossary](Narration-Aliases-and-Glossary) |
| **A/B results**: how the versions of a thumbnail or title test did | A channel's page → **What worked on YouTube** (once a test of its videos was read) | [Channels](Channels) |

## The Prompts page

The kinds of prompt run down the left, each over a few words on what it writes and with how many of each you have: **Article**, **Image**, **Thumbnail**, **Narration preparation**, **YouTube description**, **Shorts**, **Review**, **Script** and **Post**, then **Intros** and **Outros**. Pick one to list it. On a phone they are one **Showing:** choice above the list.

- The header holds **Import or export** and the button for a new one of the kind you are looking at (for example **New article prompt**).
- Above the list: **Search all prompts** and **Sort: Name ▾**. Press `/` to jump to the search box. The search looks through every kind, intros and outros included; the number beside each kind then counts the matches there, and picking a kind ends the search.
- Each row shows the name, what it **Asks for** (its keywords) and its first line, with **Edit**, **Make a video** and a **More** menu.
- Press a row to show it beside the list: its name, when it was last changed and how many versions it has, the full text, **Asks you for** (the keywords you will be asked on Create) and **Used by** (or "not used yet" on the line under the name).
- Tick rows to act on several at once. The bar above the list always shows **Select all** and the count; **Duplicate selected**, **Export selected** and **Delete selected** appear on the same line once something is ticked.

### What every row offers

| Action | What it does |
| --- | --- |
| **Edit** | Opens the prompt (or intro or outro) in its editor. |
| **Make a video** | Opens Create with this prompt picked, on the row that shows it. An article prompt switches the article to **Write it for me**, an image prompt is ticked, a thumbnail prompt turns the thumbnail on, and a description or shorts prompt turns that extra on. The rest of your draft stays as it was. |
| **More** → **Duplicate** | Opens the editor with a copy, for you to rename and save. |
| **More** → **Versions** | Opens the prompt's versions and a side-by-side compare. See [Prompts](Prompts#history-and-versions). |
| **More** → **Delete** | Asks first, then moves it to **Settings** → **Trash** for 30 days. See [Trash](Trash). |

In the prompt and the intro and outro editors, `Ctrl+S` (`Cmd+S`) saves, even while you are typing in a field.

## The Templates page

Two tabs: **Video templates** (with how many you have) and **Poster templates**. The header holds **Add starter templates** and **More** → **Import a template file (.zip)**.

Each video template is a card with a preview, its name, a line saying what it makes (shape, voice, length, captions, shorts), what it **Asks for**, and:

| Action | What it does |
| --- | --- |
| **Make a video** | Opens Create with a fresh draft made from the template. |
| **Edit template** | Opens the template's editor, in the same rows as Create. See [Edit template](Template-Studio). |
| **More** → **Duplicate** | Copies the template. |
| **More** → **Versions** | Lists the template's saved versions. |
| **More** → **Export as a file (.zip)** | Saves the template as a file you can import on another computer. |
| **More** → **Delete…** | Asks first, then moves it to the trash for 30 days. |

## Starter templates

**Templates** → **Add starter templates** adds a ready-made set for one kind of channel: prompts, a suggested voice and a video template. There are four: Sleep lore, True crime, History and Science explainers. Adding one twice changes nothing, and it never replaces a prompt or template of yours with the same name. See [Templates](Templates#starter-templates).

## Command palette shortcuts

Press `Ctrl+K` anywhere and type to find **Open Prompts**, **Open Templates**, **New prompt**, **New intro** or **New outro**, **New PDF look**, **Open PDF looks**, **Open Pronunciation**, **Open What worked on YouTube**, or a saved item by name: **Open template <name>**, **Edit prompt <name>**, **Edit intro <name>** / **Edit outro <name>** and **Edit PDF look <name>**. See [Keyboard and Ctrl+K](Keyboard-Shortcuts-and-Command-Palette).

## Fonts

There is no separate font manager. Fonts live where they are used:

- **Caption fonts:** upload your own in the **Caption font** picker in Create's **Video and style** row. Uploaded fonts then appear in a channel's brand kit too. See [Video and style](Create-Video-and-Style) and [Channels](Channels).
- **PDF fonts:** each PDF look picks its fonts from the bundled Cinzel and the fonts built into every PDF reader (Times, Helvetica, Courier). See [PDF looks](Document-Themes).

Uploaded fonts travel in backups, but templates leave them out.

## How changes reach your videos

A project copies the prompts, intros, outros, aliases and theme settings it uses when it starts. Editing a prompt later changes only runs started afterwards. Templates also keep their own copies, so save a template again to pick up a changed prompt. In a project, **Edit settings** shows the project's own copy of each prompt: pick your saved prompt again to bring in your latest edit. See [Editing a Project](Editing-a-Project).
