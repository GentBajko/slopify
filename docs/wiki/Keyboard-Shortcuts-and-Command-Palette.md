# Keyboard Shortcuts and Command Palette

The command palette lets you reach every screen, every project and the frequent actions by typing, without hunting for buttons. Keyboard shortcuts cover the most common moves. This page lists both.

**Where to find it:** press `Ctrl+K` (`Cmd+K` on a Mac) anywhere, or choose **Search or run a command** at the top of the sidebar. Press `?` for the list of keyboard shortcuts.

## Use the command palette

1. Press `Ctrl+K`.
2. Type a few letters of what you want, such as `set` for **Open settings** or `back` for **Back up now**. Letters only need to appear in order, so `crt` finds **Create**. Commands also match other words, for example `keys` finds **Open settings**. Several words match in any order across the command's name, the project it acts on and its other words: `cleopatra regenerate image 3` finds **Regenerate image 3 in Cleopatra**.
3. Use `Up` and `Down` to move through the list, `Home` and `End` to jump to the first or last, and `Enter` to run the highlighted command. You can also click a command.
4. Press `Esc` (or `Ctrl+K` again) to close the palette without running anything.

The palette lists what you can do from where you are. Commands about the screen in front of you (the project you have open, for example) are listed first, with the project or item name beside them. Some commands are only found once you type: every project by name, and New schedule and Add to calendar from other screens (see [From anywhere](#from-anywhere)). If nothing matches, it says so; try fewer letters or another word.

A command that has a shortcut shows its keys beside it.

## Keyboard shortcuts

Press `?` anywhere (outside a text field) to see **Keyboard shortcuts**: every key that works on the screen you are on. `Ctrl` works as `Cmd` on a Mac. Keys without `Ctrl` wait while you type in a field, so typing a `c` into a title never opens Play. Two keys like `G` then `H` are pressed one after the other.

| Keys | Where | What it does |
|---|---|---|
| `Ctrl+K` / `Cmd+K` | Anywhere | Opens or closes the command palette. |
| `?` | Anywhere | Shows the keyboard shortcuts. |
| `C` | Anywhere | **Create** (opens Play). |
| `G` then `H` | Anywhere | Go to Home. |
| `G` then `P` | Anywhere | Go to Projects. |
| `G` then `C` | Anywhere | Go to the Calendar. |
| `G` then `S` | Anywhere | Go to Schedules. |
| `G` then `L` | Anywhere | Go to the Library. |
| `G` then `K` | Anywhere | Go to Channels. |
| `G` then `,` | Anywhere | Go to Settings. |
| `/` | Projects, Library → Prompts, Library → Intros & outros | Puts the cursor in the list's search box. |
| `Shift+N` | A project page | Runs the project's next action (Approve, Try again, Prepare upload…). |
| `Shift+D` | A project page | Copies the YouTube description. |
| `Ctrl+S` / `Cmd+S` | The Library editors (prompts, intros and outros, document themes) | Saves, even while you are typing in a field. |
| `Up` / `Down`, `Home` / `End`, `Enter`, `Esc` | Command palette | Move, jump, run, close. |
| `Ctrl+Enter` / `Cmd+Enter` | Play | Opens **Review the whole setup** without starting a run. |
| `Space` or `K`, `J` / `L`, `Left` / `Right`, `M`, `F`, `C`, `0`–`9` | Inside a video or audio player | Play and pause, jump 10 seconds, jump 5 seconds, mute, full screen, captions, jump to a tenth of the way. See [Project Page](Project-Page#the-players). |
| `Enter` / `Shift+Enter` | Search box in a reading view (research, article, narration text, patch notes) | Next match / previous match. |
| `Left` / `Right` | Image viewer (an enlarged image or thumbnail on a project) | Previous / next image. |
| `Esc` | Dialogs, side drawers, the image viewer | Closes them. |
| `Esc` | Adding another title on Play | Cancels adding it. |
| `Esc` | Guided tour | Closes an open picker first; press again to leave the tour. |
| `Left` / `Right`, `Home` / `End` | Tabs (for example on a project page) | Move between the tabs. |
| `Left` / `Right` | Segmented choices (for example **Appearance** in Settings) | Move between the options. |

Everything else is in the palette.

## Palette commands

Commands are grouped under headings in the palette. Group names below are the headings you see.

### Go to (everywhere)

| Command | What it does |
|---|---|
| **Open home** | Goes to Home. |
| **Open projects** | Goes to Projects. |
| **Open channels** | Goes to Channels. |
| **Open schedules** | Goes to Schedules. |
| **Open calendar** | Goes to the Calendar. |
| **Open library** | Goes to the Library (Prompts). |
| **Open settings** | Goes to Settings. |
| **Open usage and costs** | Goes to Settings → Usage. |
| **Show patch notes** | Goes to Settings → Patch notes. |

### Create and Channel (everywhere)

| Command | What it does |
|---|---|
| **Create** (`C`) | Opens Play to make a new project. |
| **Show all channels** | Shows every channel's projects, schedules and costs. |
| **Switch to <channel>** | Shows one channel only. There is one command per channel. |

### From anywhere

These are found once you type, from any screen:

| Command | What it does |
|---|---|
| **Open <project>** | Opens any project by name, for example `hypatia` finds **Open Hypatia of Alexandria**. |
| **Regenerate image N in <project>** | Type the project, the words and the number, for example `cleopatra regenerate image 3`. It opens that project on its Images and asks before redrawing, as the Regenerate button does. |
| **New schedule** | Opens Schedules with a new schedule started. |
| **Add to calendar** | Opens the Calendar with the Add to calendar form. |
| **Show keyboard shortcuts** (`?`) | Lists every shortcut that works here. |

### Open a tutorial page

These tutorial pages are also inside Slopify, under **Help → Tutorials**. Type `tutorial` and a few words of a page's name, then pick **Open tutorial: <page>**, for example **Open tutorial: Install** or **Open tutorial: Shorts**. It opens that page at `/help/tutorials/<Page>`, where a search box finds any page. **Open tutorials** (under Go to) opens the tutorials' home page, and on the tutorials page `/` puts the cursor in that search box.

On the Play screen.

| Command | What it does |
|---|---|
| **Start run** / **Queue N videos** | Starts the run, or queues every video on the page. If something is missing, it takes you to the field that needs it. |
| **Add a topic for another video** | Adds another title to make a batch. |
| **Save as template** | Saves the current setup as a template. |
| **Review the whole setup** (`Ctrl+Enter`) | Opens the full review. |
| **Pick a template** | Moves to the template picker. |
| **Change title and keywords**, **Change article**, **Change narration**, **Change images**, **Change video and style**, **Change outputs**, **Change reviews**, **Change channel** | Opens that part of the setup and scrolls to it. |

On a project's page. The project's title shows beside each command.

| Command | What it does |
|---|---|
| The next action (for example **Continue the run**, **Try images again**, **Prepare upload**) (`Shift+N`) | Runs what the project page suggests next. Shows **Show the project's next action** when there is none. |
| **Pause the run** / **Continue the run** | Pauses or resumes the run. |
| **Cancel the run** | Asks to cancel the run. |
| **Prepare upload** | Opens the upload pack once the video has been made. |
| **Edit project settings** | Opens Edit project. |
| **Choose what to remake** | Opens the review of everything a change affects. |
| The first outdated group / **Remake outdated outputs** | Remakes the first group of outdated outputs. Says so when nothing is outdated. |
| **Remake everything outdated** | Remakes all outdated outputs. |
| **Save as template** | Saves this project's setup as a template. |
| **Make my own copy** | On a sample project, makes an editable copy. |
| **Open the project folder** | Opens the project's folder on this computer. |
| **Regenerate image N** / **Regenerate on-screen card N** | Redraws that image, including images behind **Show all**. Type the number, for example `regenerate image 12`. It asks first, as the Regenerate button does. |
| **Regenerate the thumbnail** / **Regenerate thumbnail N** | Redraws a thumbnail. |
| **Copy description** (`Shift+D`) | Copies the YouTube description, placeholders filled. |
| **Copy tags** | Copies the YouTube tags. |

## Tips

- The fastest way around: `Ctrl+K`, a few letters, `Enter`. For example `Ctrl+K`, `usage`, `Enter` opens your usage. For the main screens, `G` and a letter is faster still.
- On a project, `Ctrl+K` lists that project's commands first, so the next action is a few letters away (try `next` or `continue`).
- On Play, `Ctrl+Enter` is a safe way to check everything: it opens the review and never starts a run.
