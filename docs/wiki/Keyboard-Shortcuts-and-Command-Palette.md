# Keyboard Shortcuts and Command Palette

The command palette lets you reach every screen and run the frequent actions by typing, without hunting for buttons. This page lists the palette's commands and the few keyboard shortcuts Slopify has.

**Where to find it:** press `Ctrl+K` (`Cmd+K` on a Mac) anywhere, or choose **Search or run a command** at the top of the left navigation.

## Use the command palette

1. Press `Ctrl+K`.
2. Type a few letters of what you want, such as `set` for **Open settings** or `back` for **Back up now**. Letters only need to appear in order, so `nwv` finds **New video**. Commands also match other words, for example `keys` finds **Open settings**.
3. Use `Up` and `Down` to move through the list, `Home` and `End` to jump to the first or last, and `Enter` to run the highlighted command. You can also click a command.
4. Press `Esc` (or `Ctrl+K` again) to close the palette without running anything.

The palette only lists what you can do from where you are. Commands about the screen in front of you (the project you have open, for example) are listed first, with the project or item name beside them. If nothing matches, it says so; try fewer letters or another word.

## Keyboard shortcuts

| Keys | Where | What it does |
|---|---|---|
| `Ctrl+K` / `Cmd+K` | Anywhere | Opens or closes the command palette. |
| `Up` / `Down`, `Home` / `End`, `Enter`, `Esc` | Command palette | Move, jump, run, close. |
| `Ctrl+Enter` / `Cmd+Enter` | Play | Opens **Review the whole setup** without starting a run. |
| `Enter` / `Shift+Enter` | Search box in a reading view (research, article, narration text, patch notes) | Next match / previous match. |
| `Left` / `Right` | Image viewer (an enlarged image or thumbnail on a project) | Previous / next image. |
| `Esc` | Dialogs, side drawers, the image viewer | Closes them. |
| `Esc` | Adding another title on Play | Cancels adding it. |
| `Esc` | Guided tour | Closes an open picker first; press again to leave the tour. |
| `Left` / `Right`, `Home` / `End` | Tabs (for example on a project page) | Move between the tabs. |
| `Left` / `Right` | Segmented choices (for example **Appearance** in Settings) | Move between the options. |

There are no other single-key shortcuts; everything else is in the palette.

## Palette commands

Commands are grouped under headings in the palette. Group names below are the headings you see.

### Go to (everywhere)

| Command | What it does |
|---|---|
| **Open home** | Goes to Home. |
| **Open projects** | Goes to Projects. |
| **Open channels** | Goes to Channels. |
| **Open schedules** | Goes to Schedules. |
| **Open calendar** | Goes to the Calendar. |
| **Open library** | Goes to the Library (Prompts). |
| **Open settings** | Goes to Settings. |
| **Open usage and costs** | Goes to Settings → Usage. |
| **Show patch notes** | Goes to Settings → Patch notes. |

### Create and Channel (everywhere)

| Command | What it does |
|---|---|
| **New video** | Opens Play. |
| **Show all channels** | Shows every channel's projects, schedules and costs. |
| **Switch to <channel>** | Shows one channel only. There is one command per channel. |

### Play

On the Play screen.

| Command | What it does |
|---|---|
| **Start run** / **Queue N videos** | Starts the run, or queues every video on the page. If something is missing, it takes you to the field that needs it. |
| **Add a topic for another video** | Adds another title to make a batch. |
| **Save as template** | Saves the current setup as a template. |
| **Review the whole setup** (`Ctrl+Enter`) | Opens the full review. |
| **Pick a template** | Moves to the template picker. |
| **Change title and keywords**, **Change article**, **Change narration**, **Change images**, **Change video and style**, **Change outputs**, **Change reviews**, **Change channel** | Opens that part of the setup and scrolls to it. |

See [Play-Overview](Play-Overview).

### This project

On a project's page. The project's title shows beside each command.

| Command | What it does |
|---|---|
| The next action (for example **Continue the run**, **Try images again**, **Prepare upload**) | Runs what the project page suggests next. Shows **Show the project's next action** when there is none. |
| **Pause the run** / **Continue the run** | Pauses or resumes the run. |
| **Cancel the run** | Asks to cancel the run. |
| **Prepare upload** | Opens the upload pack once the video has been made. |
| **Edit project settings** | Opens Edit project. |
| **Choose what to remake** | Opens the review of everything a change affects. |
| The first outdated group / **Remake outdated outputs** | Remakes the first group of outdated outputs. Says so when nothing is outdated. |
| **Remake everything outdated** | Remakes all outdated outputs. |
| **Save as template** | Saves this project's setup as a template. |
| **Make my own copy** | On a sample project, makes an editable copy. |
| **Open the project folder** | Opens the project's folder on this computer. |
| **Regenerate image N** / **Regenerate on-screen card N** | Redraws that image. One command per image. |
| **Regenerate the thumbnail** / **Regenerate thumbnail N** | Redraws a thumbnail. |
| **Copy description** | Copies the YouTube description, placeholders filled. |
| **Copy tags** | Copies the YouTube tags. |

See [Project-Page](Project-Page) and [Video-Editing](Video-Editing).

## Tips

- The fastest way around: `Ctrl+K`, a few letters, `Enter`. For example `Ctrl+K`, `usage`, `Enter` opens your usage.
- On a project, `Ctrl+K` lists that project's commands first, so the next action is a few letters away (try `next` or `continue`).
- On Play, `Ctrl+Enter` is a safe way to check everything: it opens the review and never starts a run.
