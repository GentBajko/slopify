# Library Overview

The Library holds the reusable pieces your videos are made from: prompts, intros and outros, templates, PDF document themes and narration aliases. Write a piece once and pick it on Play for every video that needs it.

**Where to find it:** **Library** in the left rail. It opens on **Prompts**; the tabs across the top switch sections.

## The five tabs

| Tab | What it holds | Page |
|---|---|---|
| **Prompts** | The instructions for articles, images, thumbnails, narration cues, YouTube descriptions, shorts, reviews and multi-voice scripts, each with `{{keywords}}` where the subject goes | [Prompts](Prompts) |
| **Intros & Outros** | Short narrated openings and closings, written as text or generated by the text model | [Intros and outros](Intros-and-Outros) |
| **Templates** | Saved Play setups, and **Add pack** for the starter packs | [Templates](Templates) |
| **Documents** | Document themes: the look of the PDF made from the article | [Document themes](Document-Themes) |
| **Aliases** | Words the narrator says differently from how they are written, such as Dr. as Doctor | [Aliases and glossary](Narration-Aliases-and-Glossary) |

## What every Library list has

Prompts and Intros & Outros share the same row actions, in the same order:

| Action | What it does |
|---|---|
| **Edit** | Opens the item in its editor. |
| **Duplicate** | Opens the editor with a copy, for you to rename and save. |
| **Use in Play** | Picks the item in your open Play draft and opens Play on the field that shows it. An article prompt switches the article to Generate, an image prompt is ticked with one image, a thumbnail prompt switches the thumbnail to From prompt, and a Description or Shorts prompt turns that step on. The rest of the draft stays as it was. The button is off while Play is starting a run. |
| **History** | Opens the item's versions, a side-by-side compare, and what uses it. See [Prompts](Prompts#history-and-versions). |
| **Delete** | Asks first, then moves the item to **Settings → Trash** for 30 days. See [Trash](Trash). |

Your document themes have Edit, Duplicate and Delete, but no Use in Play or History. Built-in themes can only be copied.

Beside each list, the selected item shows its text, its **Keywords**, what it is **Used by**, and its latest change.

## Search and filter

- **Prompts** has a **Prompt kind** picker (Article, Image, Thumbnail, Narration Preparation, YouTube Description, Shorts, Review, Script (speakers)) and **Search prompts**.
- **Intros & Outros** has **Search intros and outros**.
- **Templates** has **Show templates of** to filter by channel.

## Command palette shortcuts

Press `Ctrl+K` anywhere and type to find **New prompt**, **New intro or outro**, **New document theme**, **Open prompts**, **Open intros and outros**, **Open templates** or **Open document themes**. See [Keyboard and Ctrl+K](Keyboard-Shortcuts-and-Command-Palette).

## Starter packs

**Library → Templates → Add pack** adds a ready-made set for one kind of channel: prompts, a suggested voice and a Play template. There are four packs: Sleep lore, True crime, History and Science explainers. Adding one twice changes nothing, and a pack never replaces a prompt or template of yours with the same name. See [Templates](Templates#starter-packs).

## Fonts

The Library has no separate font manager. Fonts live where they are used:

- **Caption (subtitle) fonts:** upload your own in the subtitle font picker on Play's video style settings. Uploaded fonts then appear in a channel's brand kit too. See [Video and style](Play-Video-and-Style) and [Channels](Channels).
- **PDF fonts:** each document theme picks its fonts from the bundled Cinzel and the fonts built into every PDF reader (Times, Helvetica, Courier). See [Document themes](Document-Themes).

Uploaded fonts travel in backups, but templates leave them out.

## How changes reach your videos

A project copies the prompts, intros, outros, aliases and theme settings it uses when it starts. Editing the Library later changes only runs started afterwards. Templates also keep their own copies, so save a template again to pick up a changed prompt. In a project, **Edit project** shows the project's own copy of each prompt: pick the Library prompt again (or press **Use the Library version**) to bring in your latest edit, and press **Update from Library** under narration aliases to copy the current alias list. See [Editing a project](Editing-a-Project).
