# Keywords Slopify fills

- **Prompts can use keywords Slopify fills itself.** Written with the reserved `Slopify_` prefix, they never become fields on Play: the video's title, channel, series brief, links, previous and next video, episode number, cast, titles covered before, brand colours and fonts, release date, chapters and length; a summary, hook, thumbnail text, key facts, quote and tags written from the article by one shared AI call; and each picture's scene, setting, mood and the looks of its figures. `{{Title}}`, `{{Channel}}` and every other name stay yours, so no existing prompt changes meaning.
- **Using a keyword turns on what fills it.** `{{Slopify_Setting}}` gives a picture its scene even with Scenes from the article off; `{{Slopify_Summary}}` adds the keyword digest to the run and to the cost estimate. The editor's Insert bar and hover cards say what each keyword fills in, an example, when it exists, which prompts can use it and what it costs; Play refuses a keyword where it can't be filled, and saving refuses an unknown `Slopify_` name.
- **`{{Scene}}` and `{{Appearance}}` keep working** as the old names of `{{Slopify_Scene}}` and `{{Slopify_Appearance}}`; the editor offers to update them. Facts are copied when a run starts, and Edit project → Prompts → Refresh keyword facts copies them again. The release date and length are filled as each step runs, so changing them never remakes anything.
