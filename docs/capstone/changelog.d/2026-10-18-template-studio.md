# Template studio

- **Set a template up once, section by section.** Library → Templates → **Open studio** shows the template's sections in the order a run makes them (Subject & research, Script, Voice, Pictures, Video & captions, Thumbnail & title, Shorts, Document, Reviews & checkpoints, Upload pack, Schedule), two to four settings each with the rest under **Fine-tune**, and a live sample beside them. Each section's lamp says whether its sample is current, being made, waiting (with why), needs a fix (with the failed step's own sentence and button), or was made for an older version.
- **Samples.** Free ones are made on this computer: a 30-second clip in the template's frame and captions, the loudness before and after, the PDF, and each schedule's cost a month. The paid sample is a short taste of one video (the outline and chapter 1, about 30 seconds of narration, four pictures, one thumbnail, one short) on a hidden project that appears in no list; a Save makes again only what it outdates and never stops work already going. Pick the **Sample topic**, **Write the full script in the sample**, fix a name with **Say it as**, and see who wrote each part of a prompt in **Prompt anatomy**.
- **Money first.** Every Save says what its sample costs; a sample that now costs more than you saw (a quarter and five cents over), has an unaccepted unknown price, or would pass **Settings → Template studio → Daily sample budget** ($2.00 by default) waits and says so. What a removed sample or discarded comparison was charged today still counts.
- **Mark ready.** Nothing changes for your schedules until you use it: they run each template's newest version, as before, and say **Not checked in the studio**. Press **Mark ready** on a version, after free checks (keywords filled, providers set up, a voice that is one of yours, release times, a known monthly cost, someone to answer each checkpoint), and from then on that template's schedules run the version marked ready; a newer Save waits to be marked ready while they keep running the ready one. Slopify's own changes keep the mark, and a retired-model switch now also switches the version your schedules run when a newer one waits.
- **Compare models.** Beside Script, Voice or Pictures, make that section's sample again on one or two other models, each on a hidden copy, and see what each made, cost and took beside the model in use. It is priced and held on the same rules; **Use this model** switches the section and you Save as usual. Settings → Models → New for you → **Compare on a sample** opens a template's studio ready for the new model.
- **Template packs.** **Export pack** saves the version marked ready as a .zip (prompts' text, voice, Look, PDF theme, a few sample files; never a key). **Import template pack** on Library → Templates checks it first, adds its prompts to your Library ("name (2)" when the name is taken by other text), and opens a new unchecked template with the pack's samples.
- **Design templates** are listed on Library → Templates too, each opened in its studio with the same rail of sections.
- **Agents.** get_template_studio, get_template_checks, quote and save tools, mark_template_ready, the bake-off (quote_bakeoff, start_bakeoff, get_bakeoff, discard_bakeoff) and import_template_pack mirror the studio; the in-app assistant asks before anything that spends, removes, marks ready or raises the budget. A pack download is a file, like a project's files.
