# Name pronunciations

- **One list decides how a name is said.** Settings → Voices → **Name pronunciations** takes a Pronunciation Glossary of your own, one `Term: /IPA/` per line, and its names come before the glossary each article writes. A name listed there sounds the same in every video, however that video's article spelled it out, so `Gygax` never drifts to `Gigax` between episodes. The page says how many names the list pronounces and names any line narration has to skip, by number and reason.
- **Each project keeps the copy it started with.** The list is copied in at start, like the narration aliases, so editing it never changes a project behind its back; **Edit settings → Narration → Use pronunciations → Copy the list again** brings the new list in, and only the narration where a changed name appears is made again.
- **The order, where two disagree:** an alias (it changes the words), then your Name pronunciations, then the article's own Pronunciation Glossary, then other projects' pronunciations while they are shared.
- **"Use the article's pronunciation glossary" is now "Use pronunciations",** because the one switch covers both your list and the article's glossary. Inworld TTS-2 and TTS-2 Flash read IPA, as before; for any other voice an alias is still the way to fix a word.
- **One save never replaces another.** Each save carries the version of the list it was made from. When a second window or an agent saved meanwhile, the save is refused with the list as it stands: the page names what changed ("An agent saved it: it has 3 names you don't have"), keeps what you typed, and offers **Save mine anyway** or **Load theirs instead**. Nothing is overwritten without the choice being made.
- **Agents can read and write it:** `get_library_pronunciations` and `set_library_pronunciations`, the save carrying `{text, version}`; a 409 names what the list is now and hands it back to save from.
