## Failure paths

- **Stage failure.** `execute` catches: aborted → `pending` (pause) or `canceled`; waitable fault with a persisted wait → `pending` with `retryAt`; otherwise logs and concludes `failed` with the fault kind (`packages/app/src/kernel/runner/index.ts:215`). `runRevisionInvocation` marks the piece `pending` (aborted) or `failed` and rethrows with a piece label (`packages/app/src/slices/rebuild/runtime-run.ts:51`). If writing the final row fails, the row stays `running`, the event still goes out and the next boot marks it interrupted (`packages/app/src/kernel/runner/index.ts:147`, `packages/app/src/main.ts:1405`). A throwing `stagesOf` during the post-run tick still re-tallies in `finally`; an escaped `execute` rejection is logged (`packages/app/src/kernel/runner/index.ts:258`, `packages/app/src/kernel/runner/index.ts:264`).
- **Provider attempt.** Aborted calls end the attempt row `canceled` and rethrow; other failures are classified, logged and retried within tier 1; terminal kinds, plan limits, exhausted attempts or long Retry-After throw to the stage (`packages/app/src/kernel/runner/attempt.ts:117`, `packages/app/src/kernel/runner/attempt.ts:141`).
- **Publication partial failure.** A failed publication transaction rolls back rows; `finally` deletes unregistered prepared files; a deletion failure leaves orphans for boot reconciliation (`packages/app/src/slices/rebuild/runtime-publication.ts:135`, `packages/app/src/slices/storage/reconcile.ts:14`).
- **Save revision.** Validation refusals return typed results; a head that moved during the transaction throws and rolls back; `finally` discards unregistered assets (`packages/app/src/slices/revisions/mutations.ts:205`, `packages/app/src/slices/revisions/mutations.ts:228`). Receipts make a resent request replay rather than mutate again (`packages/app/src/slices/revisions/mutations.ts:80`).
- **Rebuild.** Readiness exceptions become a logged `readiness` refusal before the lock; stale head/plan/cost returns `conflict`/`stale-preview` (`packages/app/src/slices/rebuild/service.ts:137`, `packages/app/src/slices/rebuild/service.ts:177`).
- **Play Start.** Expected refusals release the `starting` claim; `StartedRunMismatch` rolls back and releases; other exceptions after the claim propagate and leave durable `starting` state that a retry with the same review ID resumes. Post-commit actions catch and log independently (`packages/app/src/slices/play-drafts/start.ts:71`, `packages/app/src/slices/play-drafts/start.ts:100`, `packages/app/src/slices/play-drafts/start.ts:180`).
- **HTTP.** Uncaught route errors reach `problemFromError`: logged with a correlation ID, generic 500 to the client (`packages/app/src/edge/http/problem.ts:44`). Writes during shutdown get 503; writes during an update install get 409 (`packages/app/src/edge/http/app.ts:244`, `packages/app/src/edge/http/app.ts:260`).
- **SSE.** A rejected `writeSSE` (data or heartbeat) drops the subscriber and logs; request abort removes it.
