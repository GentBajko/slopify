# Play

## Mode & job

Operate surface at `/play` (`packages/web/src/router.tsx:92`) for turning a topic into one or more queued projects. One path: pick a template, type the topic (and more topics for more videos), press the Play key; every other setting sits folded in a summary row that opens its editor in place (`packages/web/src/routes/play.tsx:69`). `PlayRoute` navigates to `/projects/$projectId` for the first created project (`packages/web/src/routes/play.tsx:58`, `packages/web/src/routes/play.tsx:147`); `PlayForm` composes the page, and the shell-level `PlayDraftProvider` owns the autosaved draft (`packages/web/src/play/draft-context.tsx:54`).
