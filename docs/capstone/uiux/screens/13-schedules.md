# 13 Schedules

The Schedules screen extends the control-room layout with a two-column creation form and a stacked history list. It uses the existing panel, rail, label and button tokens. The primary action is Save schedule; starting work happens later in the local scheduler. Cadence, local timezone, missed-run policy, spend ceiling and keyword variants are visible before save. Each saved card shows its next local occurrence and status, with compact Pause/Resume, Cancel, History and Delete actions. History is collapsed by default to keep the next action visible.
