# Project page

## Mode & job

Operate surface at `/projects/$projectId` (`packages/web/src/router.tsx:618-623` mounts `ProjectRoute` keyed by project id, `packages/web/src/routes/project.tsx:77-85`). It shows one project's run as it happens and after it ends: what each stage made, the one action the project needs next, the run's steps, time and cost, the saved settings and their editor, review checkpoints, retained history and the rebuild review. Changing the project id remounts the whole workspace so drafts never cross projects (`routes/project.tsx:75-85`). Hidden sections stay mounted so editors and players keep their local state (`routes/project.tsx:75`, `project/stage-section.tsx:104-109`).
